# KlikTahu-

Proyek ini telah dilanjutkan dengan arsitektur mutakhir untuk menghasilkan video **Cinematic Storytelling** secara otomatis.

Silakan buka folder `KlikTahu-Video` untuk melihat source code, arsitektur *motion design*, *progressive disclosure*, dan sistem otomatisasi anti-suspend.

```bash
cd KlikTahu-Video
```
